
## Milestone 10 — Production hardening
M10 adds production-oriented governance around the M1–M9 engines: optional RBAC/API-key authentication, request audit trails, security headers, health/readiness checks, durable background-job metadata, a strictly read-only connector registry, PostgreSQL target schema, and container deployment files. See `docs/milestone-10-production-hardening.md` for boundaries and deployment caveats.
